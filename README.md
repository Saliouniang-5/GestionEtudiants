🎓 Système de Gestion des Notes Étudiantes
📖 Description

Ce projet est une application Python développée en programmation procédurale permettant de gérer les notes d'une classe d'étudiants.

Le programme offre plusieurs fonctionnalités :

Validation des notes saisies
Calcul des moyennes individuelles
Calcul des moyennes par matière
Génération de bulletins détaillés
Classement automatique des étudiants
Détection des notes manquantes
Détection des notes hors barème
Saisie interactive de nouveaux étudiants

Ce projet a été réalisé dans le cadre de l'apprentissage des bases de Python et de la programmation procédurale.
